# Оргпов: подготовка к экзамену

Тренажёр к блокирующему экзамену по курсу «Организационное поведение» (ВШБ НИУ ВШЭ, 2026).

**Открыть сайт:** https://katyhagamk-lab.github.io/orgpov-exam-prep/

## Что внутри

- 14 тем по лекциям 2026 года: теория «проще + для экзамена», 126 схем как на слайдах, ловушки и запоминалки.
- 123 задания в формате StartExam: один ответ, несколько ответов, соответствие, порядок, вставка слова, открытый вопрос. Ответы проверяются автоматически, открытые вопросы — по ключевым мыслям, с образцовым ответом.
- Подпись источника у каждого задания: «Слив 2025» (фото с экзамена 25.10.2025), «Пример преподавателя» (лекция 16), «Новое задание».
- Спринт на 6–8 часов, раздел «Ошибки» с интервальным повтором, пробный экзамен на 30 вопросов с оценкой по порогам 40/60/80%, карточки «кто автор?», шпаргалка, материалы.
- Прогресс хранится в браузере (localStorage) и переносится на другое устройство кодом.

На фото сливов ответы не отмечены. Ключи восстановлены по слайдам и разбору преподавателя, а спорные места объяснены в пояснениях к заданиям.

## Как запустить локально

Открыть `index.html` в браузере. Сборка не нужна, интернет тоже.

## Структура

- `index.html`, `styles.css`, `app.js` — интерфейс.
- `data/topics-*.js` — теория и задания.
- `data/diagrams.js`, `data/figures.js` — схемы.
- `tools/build-artifact.py` — сборка всего в один файл `dist/artifact.html`.
